# Mirai Agent

Mirai Agent 官方 Windows 安装包与自动更新下载仓库。

- [下载最新版](https://github.com/XiangZi7/MiraiAgent-releases/releases/latest)
- [全部版本](https://github.com/XiangZi7/MiraiAgent-releases/releases)

安装包以 `setup.exe` 结尾；便携版以 `portable.zip` 结尾。应用内自动更新会校验安装包签名。

`SHA256SUMS.txt` 用于核对下载文件，`version.json` 记录版本与构建提交，`latest.json` 供客户端检查更新。
